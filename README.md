# ARSborcaRobotov

AR сборка робота 

📱 О проекте

Интерактивное AR-приложение для обучения основам робототехники через технологию дополненной реальности. Приложение проецирует пошаговые 3D-инструкции прямо на маркереа, упрощая процесс сборки и делая обучение более 
наглядным и увлекательным.

🎯 Ключевые особенности

Маркерная AR-система на базе Vuforia Engine

Библиотека 3D-моделей деталей роботов (7 оптимизированных моделей)

Интуитивный интерфейс с пошаговой навигацией

Кроссплатформенность (поддержка Android)

Быстрое распознавание маркеров (1-2 секунды)



🛠 Технологический стек

Технология	Назначение

Unity 2021 LTS	Основная среда разработки AR-приложения

Vuforia Engine	Распознавание и отслеживание маркеров

Blender 3.0+	Создание и оптимизация 3D-моделей

C#	Программирование логики приложения

Visual Studio 2022	Интегрированная среда разработки

Установка:

Ссылка на скачку : https://disk.yandex.ru/d/j4TaRI_PU1YdNw

Скачайте APK-файл

Разрешите установку из неизвестных источников в настройках Android

Установите приложение

Распечатайте маркеры из папки Маркеры
Запустите приложение и наведите камеру на маркер

🎮 Использование приложения

Подготовка рабочего места с достаточным освещением

Разложите детали робота и соответствующие маркеры

Запустите приложение и наведите камеру на маркер 

Следуйте 3D-инструкциям, которые появятся на экране

Используйте кнопки навигации ("Далее"/"Назад") для перехода между этапами

Соберите робота, повторяя шаги для каждой детали
